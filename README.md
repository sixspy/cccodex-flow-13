## 前置依赖图（flow-13）

每个下游任务可挂一个前置依赖图，依赖态与运行详情并列展示，所有闸口由后台强制，前端只负责呈现：

- **同轮钉死**：保存依赖图时一并钉死依赖策略与抽取路径，当日不许再换，次日才可重配。
- **两种策略**
  - `作废`：前置未齐件时点抽取 → 下游置「已中断」，写入中断缘由并累加中断数。
  - `等待舱`：前置未齐件时点抽取 → 下游进「等待舱」，须填强抽缘故、人工确认后才强行开抽，确认痕迹单独留痕可核。
- **前置齐件闸**：前置态为「已抽取待落库 / 已落库」才算齐件，未齐不能开抽。
- **路径漂移闸**：当前路径与钉死路径不一致即拦截，并在页面回写中文原因。
- **抽取锁与争用**：原子抢注，同刻并抽只留先手，败方记「下游争用败绩」。
- **入口可见性**：前置仍在抽取时，下游抽取入口保持看不见（`extract_entry_visible=false`）。
- **空图禁存**：下游至少挂一个前置任务编号，空依赖图不准保存；同时拒绝自环与成环。

### API

| 方法 | 路径 | 说明 |
|----|----|----|
| GET | `/api/flows/<id>` | 运行详情 + 依赖块（前置态、齐件闸、策略名、等待舱、中断数、入口可见性） |
| PUT | `/api/flows/<id>/dependencies` | 钉死保存依赖图与策略（空图/成环/当日换策略均拒） |
| PUT | `/api/flows/<id>/source-uri` | 更新抽取路径（漂移后开抽被拦） |
| POST | `/api/flows/<id>/extract/start` | 开抽：路径漂移、齐件闸、争用、策略处置全部后台强制 |
| POST | `/api/flows/<id>/extract/finish` | 抽取收尾 |
| POST | `/api/flows/<id>/extract` | 开抽并立即收尾 |
| POST | `/api/flows/<id>/force-extract` | 等待舱人工确认强行开抽（须强抽缘故） |
| GET | `/api/flows/<id>/confirmations` | 等待舱人工确认痕迹，可单独核对 |
| POST | `/api/flows/<id>/land` | 落库 |

> 路由参数统一使用 Sanic Routing 的 `<flow_id:int>` 写法；`regex` 是类型转换器的硬依赖，已列入 requirements。
